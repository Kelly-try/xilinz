# 乐脉 · 音乐家地理与师承谱系

一个免安装的单页交互原型。用浏览器打开 index.html 即可使用。

## 当前内容

- 可拖动旋转的 SVG 地理半球，标出维也纳、魏玛、费城、东京、坦格尔伍德与加拉加斯。
- 钢琴家与指挥家的试用档案：12 位音乐家、8 条有来源的师承或培养关系。
- 地点、人物、谱系卡片与筛选器互相联动；关系详情提供原始机构来源链接。
- 自动旋转、搜索、响应式布局与简要的平台说明弹窗。

## 文件

- index.html：页面结构
- styles.css：视觉样式与响应式布局
- app.js：半球绘制、示例档案与交互逻辑
- render.yaml：Render 静态站点 Blueprint 配置

## Render 发布

此目录需先放入 Git 仓库，再在 Render 选择 Blueprint 创建服务。配置会把 HTML、CSS 与 JavaScript 复制到公开站点目录；README 和 Blueprint 文件不会被发布为网页内容。Render 会为站点分配 onrender.com 地址。

档案目前是小规模示例，用于验证地图与谱系的浏览方式；它不代表完整音乐史数据库。关系的性质会区分师生、训练经历与培养提携。
